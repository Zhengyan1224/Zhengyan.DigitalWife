# 镜面反射采样级别

GameEditor 中，平面和水面的 `Mirror reflection` 开关下面提供 `Mirror reflection samples` 选项。
可选级别为 1x、2x、4x、8x、16x，上限跟随项目窗口的场景 MSAA 设置。
每个平面和水面分别保存 `mirrorReflectionSamples`，修改后即时用于编辑器预览，并随场景保存和游戏包导出。
旧项目未设置该字段时默认为 1x。

运行时，反射采样不超过场景实际使用的级别。颜色和深度附件均支持的最高级别才会被采用；
例如请求 8x，而设备仅支持 4x，则使用 4x；若没有可用的多重采样级别，则使用 1x。
OpenGL / OpenGL ES / WebGL2 还会在多重采样帧缓冲创建失败时继续尝试较低级别。

PC OpenGL、Android OpenGL ES 和 WebGL2 使用多重采样颜色/深度附件，完成反射后解析到普通颜色纹理。
PC 和 Android Vulkan 使用同一套多重采样反射目标与颜色解析实现。
Web 水面的反射使用反射摄像机与视角相关的混合强度；Web 的完整水波和水下效果仍属于现有的渲染功能差异。

反射采样影响几何边缘抗锯齿，反射纹理分辨率由已有的分辨率策略控制。
Android 质量配置仍控制反射开关、表面数量及分辨率；Web 的场景实际采样上限同时受浏览器画布抗锯齿能力限制。
