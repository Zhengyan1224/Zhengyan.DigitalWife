# Zhengyan.DigitalWife.Tools.ApiInspector

`Zhengyan.DigitalWife.Tools.ApiInspector` 是仓库内部的第三方 API 反查工具，主要用于排查 `SherpaOnnx`、`Whisper.net`、`PortAudio` 等依赖包公开的运行时 API。

## 运行

```powershell
dotnet run --project tools/Zhengyan.DigitalWife.Tools.ApiInspector/Zhengyan.DigitalWife.Tools.ApiInspector.csproj
```
