def gui_event(entity, scene, input, audio, control_id, control_name, event_name):
    if event_name == "clicked":
        scene.llm.start_chat(
            "写一句欢迎语",
            on_delta="reply_delta",
            on_completed="reply_done",
            on_error="reply_error")

def reply_delta(entity, scene, input, audio, event):
    label = scene.get_gui_control("LLM Output")
    if label:
        label.set_value(event["accumulatedText"])

边界

  • Python 对象多数是事件开始时的快照，修改命令通常在函数返回后由 GamePlayer 执行；需要中途提交可用 scene.flush()。
  • C# 脚本每次事件都会重新执行同一个 `.csx` 文件，跨帧状态建议放在 static 类型中。
  • GUI 和 Sprite 坐标以窗口左上角为原点；`relative` 布局会按项目窗口基准分辨率缩放。
  • PMX 动作、Morph、骨骼、材质覆盖、TTS 口型和绑定关系只对 pmx_model 有意义。
  • OpenCL 会在不可用时回退 CPU；脚本应读取 ComputeBackend 判断实际后端。
