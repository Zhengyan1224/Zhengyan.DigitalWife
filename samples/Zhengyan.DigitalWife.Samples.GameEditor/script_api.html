scene.flush()

Python 里的 scene.bubble.names / visible_names 是当前脚本事件快照；如果你在同一事件里修改后想立刻刷新画面，记得调用 scene.flush()。

完整的“按住录音 ASR - 可编辑文本框 - 点击发送 - 气泡流式回复 - 句子级顺序 Speak”联动示例请看同目录的 script_api.md，示例会同时串起 Scene.Asr、Scene.Llm、Scene.Bubble 和 SpeakWithCallback(...)。

边界

  • Python 对象多数是事件开始时的快照，修改命令通常在函数返回后由 GamePlayer 执行；需要中途提交可用 scene.flush()。
  • C# 脚本每次事件都会重新执行同一个 `.csx` 文件，跨帧状态建议放在 static 类型中。
  • GUI 和 Sprite 坐标以窗口左上角为原点；`relative` 布局会按项目窗口基准分辨率缩放。
  • PMX 动作、Morph、骨骼、材质覆盖、TTS 口型和绑定关系只对 pmx_model 有意义。
  • OpenCL 会在不可用时回退 CPU；脚本应读取 ComputeBackend 判断实际后端。
  • Realtime Voice 的 start_* 是后台任务；不要在每帧 update 里重复触发，否则会持续创建并发请求。
  • start_transcription / start_voice_turn 支持超时回调，适合实现“30s 未继续说话则回到唤醒词模式”的对话状态机。
